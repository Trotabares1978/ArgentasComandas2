# Argentas

Nueva reconstrucción de Argentas para dos terminales, con sincronización bidireccional como núcleo.

## Principios
1. La conexión entre terminales es infraestructura crítica.
2. Todo cambio comercial importante se registra como operación identificable.
3. Una operación no se considera entregada hasta recibir confirmación del otro terminal.
4. Las operaciones pendientes sobreviven cierres, reinicios y cortes de conexión.
5. La reconexión reanuda automáticamente la cola.
6. Ambos terminales pueden enviar y recibir.
7. La interfaz conserva la identidad visual de Argentas.
8. Se preservan las mejoras posteriores del Argentas-Comandas original, incluida la calculadora moderna y sus accesos de $10.000 y $20.000.

## Referencias
