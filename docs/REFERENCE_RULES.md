# Reglas de referencia para Argentas 2

La APK aportada es referencia de comportamiento y estética, no un reemplazo automático del código posterior.

## Se conserva
- calculadora de cobro actual;
- botones laterales de $10.000 y $20.000;
- pagos combinados;
- cálculo de vuelto/faltante;
- eliminación del globo flotante;
- mejoras de Vender -> Comandas;
- mejoras de Wi-Fi Direct;
- ACK, reintentos y diagnóstico;
- cualquier mejora posterior validada.

## Se recupera de la APK cuando sea mejor
- estructura visual;
- imágenes y recursos;
- comportamiento estable de pantallas;
- lógica de Comandas que demuestre ser más robusta.

Nunca se reemplaza una mejora posterior simplemente por existir en la APK antigua.
